AI Usage Ledger
---------------
- Records successful Voice GPT and GPT Vision calls.
- Stores model, input/output/total tokens, timestamp, and optional estimated USD cost.
- Worker returns token usage from OpenAI Responses API.
- Optional cost estimate uses Worker variables:
  OPENAI_INPUT_USD_PER_1M
  OPENAI_OUTPUT_USD_PER_1M
  OPENAI_VISION_INPUT_USD_PER_1M
  OPENAI_VISION_OUTPUT_USD_PER_1M
- If rates are not configured, the ledger still records exact token usage and shows cost as unavailable.
- Official OpenAI billing remains the financial source of truth.
