Build046 changes
----------------
1. Safe Context Follow-ups
   - Supports: 有多少 / 还有多少 / 有几卷 / How many do we have / How many do you have / Where is / Which rack.
   - These inherit only the last confirmed product entity.
   - Current-turn quantity/location intent remains authoritative.

2. Entity Safety
   - Fuzzy or phonetic jumps to a different product family are not answered automatically.
   - The assistant asks the user to confirm the new product.
   - Exact product names and explicit alias-dictionary matches still switch immediately.

3. Context Quality
   - Successful context prefers a canonical product-family entity rather than a random color/variant when possible.
   - Short unclear fragments still trigger clarification.
